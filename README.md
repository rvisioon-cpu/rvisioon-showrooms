# RVISIOON Showrooms

Interfaz web para explorar los showrooms virtuales de Océano Atlántico, El Olimpo de Tumbes, Santa Fe, Venecia, Altamira Park y Saint Elliot.

- Fotografías horizontales y miniaturas ligeras.
- Flechas para seleccionar, Enter/OK para abrir.
- Configuración local para ordenar, mostrar u ocultar proyectos y añadir enlaces HTTPS.
- Importación y exportación de la selección en JSON.

Los recorridos requieren conexión a internet. La configuración se guarda por navegador; no se comparte entre dispositivos. La compatibilidad con un mando físico depende del navegador o del contenedor Android TV y está pendiente de validación en el dispositivo.

## Desarrollo local

Servir esta carpeta con cualquier servidor estático y abrir `index.html`.

## Publicación

GitHub Pages desde la rama `main`, carpeta raíz.

Marca y fotografías de RVISIOON y sus respectivos proyectos. Las licencias de las tipografías se incluyen en `assets/`.
